# audio-agent

English speaking/listening practice voice agent — three minimal demos, one per git worktree:

| Branch | Stack |
|---|---|
| `demo/hf-s2s` | Hugging Face speech-to-speech |
| `demo/pipecat` | Pipecat |
| `demo/livekit` | LiveKit Agents |

LLM: DeepSeek official API (OpenAI-compatible, `https://api.deepseek.com`). Key goes in `.env` (gitignored) as `DEEPSEEK_API_KEY`.
